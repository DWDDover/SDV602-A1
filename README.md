# SDV602 Assessment 1

## Installing Dependencies

In the terminal from the project root type:

```pip install -r requirements.txt```

## Running the application

In the terminal change the directory to the /game folder:

```cd game```

Then start the game:

```python program.py```

The game has a list of commands within the game window.

## Testing

To test the application inside the /game folder use:

```python program.py --headless```

The game scenarios will run and print the output for each command or any errors that occur
